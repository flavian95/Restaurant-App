# 🍽️ Restaurant App

A full-stack web application that allows users to browse a restaurant's menu and order their favorite food items online. Built with a robust Laravel backend and a responsive Bootstrap frontend.

## ✨ Features

* **Interactive Menu:** Users can browse through available food items organized by categories.
* **Order Management:** Seamlessly add items to a cart and place an order.
* **Responsive Design:** A mobile-friendly user interface styled with Bootstrap ensures a great experience on any device.
* **Secure Backend:** Powered by Laravel, ensuring secure data handling and efficient routing.
* **Database Integration:** MySQL database handles menus, orders, and user data effectively.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap
* **Backend:** PHP, Laravel Framework
* **Database:** MySQL

### Prerequisites

* [PHP](https://www.php.net/) (v8.0 or higher recommended)
* [Composer](https://getcomposer.org/)
* [MySQL](https://www.mysql.com/)
